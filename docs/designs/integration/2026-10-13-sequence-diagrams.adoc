  else Terminal failure
    provider --> int: 4xx/unsupported payload
    int -> db: [SQL] Commit FAILED_TERMINAL + safe code
    int ->> bus: [EventBridge/SQS async] InvoiceFailed.v1
  end
end

== Diagram notes

* All event arrows use EventBridge/SQS with at-least-once delivery; consumers deduplicate before side effects.
* All provider calls use adapter boundaries and stable idempotency keys; provider response is normalized before persistence.
* `OrderPaid.v1` remains the only canonical paid-order fact; `PaymentPaid.v1` is not an invoice trigger.
* Demo Control Plane never reads or writes parent databases directly and is deployed only in non-production.
* X-Ray/OpenTelemetry references are redacted and may be degraded without changing business state; the checkpoint records trace quality.
