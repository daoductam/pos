:toc:
:sectnums:

Ngày: 2026-10-13

Các sơ đồ là design-level diagrams. Repository chưa có Recommendation implementation source; các service và provider ngoài boundary được biểu diễn theo contracts đã xác nhận.

== Participants

L1 biểu diễn POS, Recommendation, Order, Catalog, Inventory, Loyalty, EventBridge/SQS, Reporting/Audit và DeepSeek khi flow liên quan.

L2 tập trung vào Controller, Application Service, Order Context Client, Eligibility Projection, Rule/Model Runtime, Recommendation DB và Outbox/ML Worker; không biểu diễn Repository/DAO riêng.

rec --> worker: HTTP 202 runId

order --> worker: OrderPaid facts/source watermark
worker -> store: [HTTPS] Write immutable training snapshot
store --> worker: Snapshot URI/checksum
worker -> worker: Train ALS per tenant in isolation
worker -> rec: [HTTP/REST] Submit candidate metrics/artifact manifest

alt Quality/privacy/isolation gates pass
  rec -> db: CAS active pointer to candidate model
  rec ->> bus: [EventBridge async] RecommendationModelActivated.v1
  rec --> worker: HTTP 200 ACTIVE
else Gate fails or training error
  rec -> db: Keep previous active model; mark REJECTED/FAILED
  rec ->> bus: [EventBridge async] RecommendationTrainingRunCompleted.v1
  rec --> worker: HTTP 200 RETAIN_PREVIOUS
end
@enduml

== Design notes

* Recommendation không đọc trực tiếp Order/Catalog/Inventory/Loyalty DB; Order context là bounded internal API hoặc matching local projection, các nguồn còn lại đi qua versioned events/projections.
* Order add-line là authority cuối. Recommendation stale hoặc analytics/provider failure không tự làm checkout fail.
* `SuggestionAccepted` chỉ được ghi sau add-line success evidence; `OrderPaid.v1` vẫn là canonical revenue/training fact.
* ALS model/rule versions và projection watermarks được trả/ghi để có thể replay, rollback và audit.
* DeepSeek/weather không nằm trên P0/P1 realtime path.
