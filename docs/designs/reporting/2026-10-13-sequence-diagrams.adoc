== Scope and traceability

Các sơ đồ dưới đây là **contract-driven design diagrams**. Repository chưa có Reporting implementation source, nên participant/message được lấy từ Requirements và Architecture đã được user xác nhận; đây chưa phải runtime code trace.

* L1 biểu diễn system-level communication.
* L2 biểu diễn các component quan trọng bên trong Reporting; repository/DAO được collapse vào database boundary.
* Dashboard chỉ đọc Reporting read model; không query chéo database domain.
* Mọi flow giữ tenant/branch scope, watermark, projection version và data-quality semantics.
